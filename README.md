# 即梦 3.0 视频提示词技能

把一句模糊的创意，改写成即梦更容易理解和执行的中文视频提示词。

这个 Codex Skill 面向即梦视频 3.0 / 3.0 Pro，支持文生视频、图生视频、图文生视频、首尾帧、连续动作、双人互动和竖屏短剧分镜。

## 它能做什么

- 将故事梗概改写成可直接使用的即梦提示词
- 区分文生视频与图生视频的写法
- 明确主体、动作、方向、速度和幅度
- 设计景别、视角、运镜、光线与情绪
- 把复杂动作拆成可靠的时序步骤
- 诊断动作漏失、角色混乱、肢体崩坏和图生视频不保真
- 为同一创意输出简洁版、电影版、动作版或保守版
- 将短剧脚本整理成带时间顺序的竖屏分镜提示词

## 效果示例

输入：

> 迟野下班经过沈逾白办公室，发现他肚子疼，进去问他怎么了。

输出：

> 竖屏9:16，约10秒，现实主义都市情感短剧，深夜写字楼，冷灰色低饱和色调，办公室内透出柔和暖光。迟野下班后独自走在安静的公司走廊里，镜头以侧面中景平稳跟拍。经过敞开的办公室门时，迟野放慢脚步并转头看向门内。镜头顺着他的视线摇入办公室：沈逾白面色苍白地坐在办公桌后，一只手用力按住腹部，身体微微蜷缩。切回迟野近景，他的神情由冷淡转为担忧，随后快步走进办公室，在沈逾白身旁停下并微微俯身询问：“沈逾白，你怎么了？肚子不舒服？”镜头缓慢推近两人，保持角色外貌、服装和空间位置前后一致，表演自然克制，对白口型清晰。

更多成品示例见 [`references/examples.md`](references/examples.md)。

## 使用

直接调用技能：

```text
使用 $jimeng-video-prompt，把“一位剑客在雨夜竹林拔剑”改写成即梦视频提示词。
```

也可以提出更具体的要求：

```text
使用 $jimeng-video-prompt，把这张参考图改写成图生视频提示词，人物先回头，再看向镜头，镜头缓慢推近。
```

```text
使用 $jimeng-video-prompt，诊断这段提示词为什么没有执行第二个动作，并给我三个稳定版本。
```

## 核心方法

文生视频：

```text
主体 + 动作 + 场景 + 镜头 + 风格 +（情绪）+（照明）
```

图生视频：

```text
动作 + 镜头 +（情绪/照明变化）
```

复杂动作默认控制在三个主要节拍以内，并使用“先、随后、然后、最后”明确顺序。双人场景始终使用稳定角色标签，避免“他”“对方”等模糊指代。

## 项目结构

- `SKILL.md`：核心工作流、可靠性检查和失败恢复
- `references/patterns.md`：模板、运镜、美感控制与诊断表
- `references/examples.md`：完整成品示例与失败提示词改写
- `agents/openai.yaml`：Codex 技能界面信息

## 适用范围

本技能针对提示词设计与优化，不直接生成视频，也不保证高难度打斗、舞蹈、跑酷或复杂物体交互一次成功。对于高风险动作，它会优先简化动作、减少主体、降低运镜复杂度或建议拆分生成。
